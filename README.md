# 🎧 Spotify Listening Analytics Dashboard

An interactive Power BI dashboard designed to analyze Spotify listening
behavior, trends, artist preferences, platform usage and listening patterns.

---

## 📊 Project Overview

This project analyzes approximately 149,861 Spotify listening records
to uncover meaningful patterns in listening behavior.

The goal was not just to visualize the data, but to transform raw
listening history into an interactive and easy-to-understand analytics
experience.

---
## 📂 Dataset

The dataset used in this project is a Spotify listening history dataset
containing approximately **149,861 listening records**.

The dataset includes information such as:

- 🎵 Track name
- 🎤 Artist name
- 💿 Album name
- 🕐 Listening timestamp
- 📱 Platform
- ⏱️ Listening duration
- 🔀 Shuffle status
- ⏭️ Skip status
- ▶️ Reason for starting playback
- ⏹️ Reason for ending playback

## 🎯 Project Objective

The main objective of this project was to understand how personal
listening behavior can be transformed into meaningful analytical
insights using Power BI.

Rather than creating static charts, the dashboard focuses on
interactive exploration through filters, navigation and dynamic
measures.
